## Desviaciones (con razón)

1. **Node del entorno.** `/usr/bin/node` es v12.22.9 → Biome/Vitest rompen antes de
   correr (`SyntaxError: Unexpected token '.'`). Se agregó `.nvmrc` (22.23.2);
   hay que `nvm use` (o `nvm install`) antes de cualquier `npm`.
2. **Biome schema.** El spec pedía schema 1.9.4, pero lo instalado es Biome 2.5.14.
   Adaptado a 2.x: `files.ignore` → negaciones en `files.includes` + `vcs.useIgnoreFile`;
   `organizeImports` → `assist.actions.source.organizeImports`; `--apply` → `--write`.
3. **`lint` conserva `--no-errors-on-unmatched`.** Sin el flag, `biome check src/`
   sale 1 ("No files were processed") mientras `src/` no tenga `.ts`, haciendo rojo
   cada commit intermedio. Con el flag, todos los commits quedan verdes.
4. **`tests/setup.ts` sin `jest-native`.** `import '@testing-library/jest-native/extend-expect'`
   arrastra `react-native` (Flow) que Vitest no transforma →
   `SyntaxError: Unexpected token 'typeof'`, y el suite entero falla. `@testing-library/jest-native`
   está deprecado; RNTL 14 trae los matchers integrados. El paquete queda instalado
   (por spec) pero sin importar.
5. **`JSX.Element`.** React 19 eliminó el namespace global `JSX`. Se agregó
   `import type { JSX } from 'react'` en `HomeScreen`, `RootNavigator` y `App`.
6. **Orden de tareas ajustado.** El spec crea `RootNavigator` (T5) importando
   `HomeScreen` (T10), inexistente al momento de T5 → typecheck rojo. Se hicieron
   tema (T9) y HomeScreen (T10) antes de la navegación (T5). El estado final es idéntico.
7. **`vitest.config.ts` (spec) reintroduce un warning benigno de Vite**
   (config ESM cargada como CJS). El pass de gobernanza lo evitaba con `.mts`.
   Se respetó el nombre pedido; silenciable con `.mts` o añadiendo el extra
   correspondiente. No afecta el gate.
8. **`tsconfig` sin `baseUrl`.** `baseUrl` dispara TS5101 (deprecado) bajo TS ~6.0.3;
   los `paths` van `./`-relativos.
9. **Aliases de Vitest** en forma con barra (`@core/`) y con los específicos antes
   que `@`, para que `@` no secuestre `@core`/`@react-navigation` (el config del
   spec los deja invertidos y rompería esos imports).
10. **`mobile-plan-v2.md` no existe** en `../Mola_Universe_APP/docs/planning/`
    (solo `fase-0.*`, `roadmap.md`, `sprints.md`, `tests-baseline.md`). No se usó.
11. **Mismatch de env.** El cliente usa `EXPO_PUBLIC_API_URL`; `.env.example` aún
    declara `API_URL`/`API_TIMEOUT_MS` (sin prefijo `EXPO_PUBLIC_`). Alinear en M1.
